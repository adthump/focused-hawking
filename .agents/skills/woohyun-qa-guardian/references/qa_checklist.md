# 📋 우현이 관찰 시스템 QA 시험 매트릭스 및 체크리스트

## 1. SWUT (Software Unit Test) 19종 검증 기준
- **TC-UT-01 (ISO 날짜)**: `YYYY-MM-DD` 형식, 윤년(2024-02-29 허용 / 2026-02-29 거부)
- **TC-UT-02 (요일 연동)**: 날짜 기반 요일(월~일) 매핑 일치
- **TC-UT-03 (약물 규격)**: 약물명 필수, 용량 단위(0.5mg, 0.25mg, 10mg, 18mg, 0.5정) 검증
- **TC-UT-04 (기분 척도)**: `밝음(4)`, `평온(3)`, `불안(2)`, `가라앉음(1)`
- **TC-UT-05 (리바운드 척도)**: `없음(1)`, `보통(2)`, `짜증 심함(3)`
- **TC-UT-06 (집중 시간 경계값)**: 0~180분 정수, 음수 및 NaN 거부
- **TC-UT-07 (다중 투약 보존)**: 병용 투약 시 배열 구조 누락 없이 보존
- **TC-UT-08 (식사량 척도)**: `정상`, `평소의 70%`, `거의 안 먹음`
- **TC-UT-09 (집중도 평균)**: 빈 배열(0건) 시 0 반환 (0으로 나누기 방어)
- **TC-UT-10 (리바운드 발생률)**: `보통`+`짜증 심함` 일수 백분율(%)
- **TC-UT-11 (긍정 정서율)**: `밝음`+`평온` 일수 백분율(%)
- **TC-UT-12 (식욕 부진율)**: `평소의 70%`+`거의 안 먹음` 점심 식사 비율(%)
- **TC-UT-13 (약물 적정 델타)**: 변경 전후 지표 증감치(Delta) 부호 및 수치 연산
- **TC-UT-14 (MIME 타입)**: `.html`, `.js`, `.css`, `.json`, `.xlsx`, `.png` 등 확장자 매핑
- **TC-UT-15 (IP 감지)**: 비-루프백(127.0.0.1 제외) IPv4 인터페이스 자동 선별
- **TC-UT-16 (날짜 정렬)**: 날짜 오름차순(과거 ➡️ 최신) 정렬 보장
- **TC-UT-17 ~ 19 (엑셀 변환)**: Record JSON 객체와 엑셀 한글 컬럼 간 양방향 직렬화

## 2. SWIT (Software Integration Test) 11종 검증 기준
- **TC-IT-01**: `GET /` 루트 호출 시 index.html 정상 서빙 (HTTP 200)
- **TC-IT-02**: 존재하지 않는 파일 요청 시 404 Not Found 반환
- **TC-IT-03**: `OPTIONS /api/records` CORS 프리플라이트 헤더 반환 (HTTP 204)
- **TC-IT-04**: `GET /api/info` 로컬 네트워크 IP 및 상태 반환 (HTTP 200)
- **TC-IT-05**: `GET /api/records` 초기 기록 목록 조회 (HTTP 200)
- **TC-IT-06**: `POST /api/records` 날짜 누락 비정상 요청 거부 (HTTP 400)
- **TC-IT-07**: `POST /api/records` 신규 관찰 기록 등록 (HTTP 200)
- **TC-IT-08**: `POST /api/records` 동일 날짜 수정 Upsert 검증 (HTTP 200)
- **TC-IT-09**: `POST /api/records/import` 대량 동기화(배치 머지) 검증 (HTTP 200)
- **TC-IT-10**: `DELETE /api/records/:date` 특정 날짜 삭제 (HTTP 200)
- **TC-IT-11**: `DELETE /api/records/:date` 미존재 날짜 삭제 시 404 처리
