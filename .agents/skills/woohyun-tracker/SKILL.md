# 💻 우현이 관찰 시스템 핵심 개발 스킬 (Woohyun Tracker Dev)

이 스킬은 우현이의 일일 관찰 기록표 웹 애플리케이션의 사용자 인터페이스(UI), 데이터 수집 폼, 시각화 대시보드, 로컬 서버 REST API를 개발하고 유지보수하는 전담 개발(Dev) 스킬입니다.

---

## 🛠️ 제공 도구 및 개발 가이드

### 1. 관찰 데이터 통계 및 트렌드 분석기
누적된 관찰 기록 데이터를 바탕으로 평균 집중 시간, 약물 조합별 효과, 리바운드 발생률, 식욕 저하 패턴을 분석합니다.
- **실행 명령**:
  ```bash
  node .agents/skills/woohyun-tracker/scripts/analyze_data.js
  ```

### 2. 엑셀 템플릿 생성기
SheetJS 기반 엑셀 연동 템플릿(`.xlsx`)을 자동 빌드합니다.
- **실행 명령**:
  ```bash
  node generate_excel.js
  ```

## 🔄 개발 및 검증 워크플로우 (Dev-QA 분리 & 3대 핵심 개발 지침)

1. **아동 존중 및 비낙인 언어 준수 (Child-Friendly & Non-Stigmatizing)**:
   - UI 텍스트, 뱃지, 차트 라벨, 도움말 작성 시 아이가 화면을 보더라도 상처받거나 낙인감을 느끼지 않도록 **병명/진단명(ADHD 등)을 일체 노출하지 않습니다.**
   - `성장 발달`, `집중력 몰입`, `생체 리듬`, `정기 진료 & 상담` 등 아이의 성장을 돕는 따뜻하고 긍정적인 표현을 표준으로 사용합니다.

2. **5대 관찰 블록 순서 불변 원칙 (Clinical Section Order Invariance)**:
   - 부모님의 하루 일과 루틴 및 병원 문진 흐름에 맞추어 다음 5대 섹션 순서를 **어떠한 레이아웃 개편 시에도 절대 변경하지 않습니다**:
     1. `1. 💊 처방 약물 & 복용 순응도` (다중 약물/용량/시간)
     2. `2. 🌙 수면 & 식사량 밸런스` (생체리듬 및 점심 식욕)
     3. `3. 🎯 약효 피크 평가: 오후 4시 수학 집중도` (최대 약효 과제 몰입)
     4. `4. ⚡ 약효 소진기: 저녁 리바운드 & 감정 날씨` (약효 소진 및 감정 기복)
     5. `5. 🩺 신체 이상 증상, 틱(Tic) 관찰 및 학교 피드백` (부작용 및 관찰 메모)

3. **한국어 타이포그래피 표준 (Word-Break Rule)**:
   - 반응형 화면 축소 시 `"리바운 / 드"`, `"피크 / 지표"`처럼 한글 단어 중간 음절이 분절되지 않도록 스타일시트 및 레이아웃에 **`word-break: keep-all;`**을 전역 필수 적용합니다.

4. **모바일 390px 초소형 뷰포트 레이아웃 안전 표준**:
   - 약물 입력 행은 모바일에서 `[약물 셀렉트] [삭제]` 1행 + `[-] [용량] [+]` 2행의 유연한 flex-wrap 구조를 적용합니다.
   - 기상/취침 시간 인풋은 모바일 2열 나란히 배치 시 넘침이 없도록 `w-8 sm:w-10` 컴팩트 폭을 유지합니다.
   - 기분 선택 및 세그먼트 버튼은 가로 100% 폭에 균등 분할(`flex-1`)하여 터치 타겟을 보장합니다.

5. **기능 개발 및 UI 수정**:
   - `index.html` 또는 `server.js`에서 기능 개발 및 버그 수정을 진행합니다.

6. **독립 QA 검증 위임 (woohyun-qa-guardian)**:
   - 개발 완료 후 즉시 **`woohyun-qa-guardian`** 스킬을 호출하여 `npm test` (SWUT 19종 + SWIT 11종 + SWVT 5종 = 총 35종) 전수 시험을 실행하고 합격 여부를 판정받습니다.
   - 필요 시 `npm run capture:ui`를 실행하여 모바일(390px) 및 PC(1280px) 실기기 캡처를 생성하고 시각적 무결성을 최종 검증합니다.

7. **회귀 방지 확인**:
   - QA 스킬에서 불합격된 항목이 발견되면 에러 로그를 기반으로 수정 후 재검증을 의뢰합니다.
