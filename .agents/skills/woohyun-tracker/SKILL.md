# 📋 우현이 관찰 기록 & 분석 하네스 스킬 (Woohyun Tracker)

이 스킬은 우현이의 일일 관찰 기록 시스템의 품질을 보증하고, 약물 반응, 학습 집중도, 식사/수면, 정서적 변화(리바운드 등) 데이터를 다각도로 분석하여 보호자와 전문의 상담을 지원합니다.

---

## 🛠️ 제공 도구 및 헬퍼 스크립트

### 1. 종합 시스템 검증 하네스 (32개 지표 전수 검증)
웹 애플리케이션 컴포넌트, 모바일 하단 탭 바 및 카드 뷰, REST API 서버, 엑셀 템플릿 무결성, 스키마 유효성, 점수 계산 로직을 자동 검증합니다.
- **실행 명령**:
  ```bash
  node .agents/skills/woohyun-tracker/scripts/run_harness.js
  ```

### 2. 관찰 데이터 통계 및 의사 상담 리포트 생성기
누적된 관찰 기록 데이터를 분석하여 평균 집중 시간, 약물 조합별 효과, 리바운드 발생률, 식욕 저하 패턴을 도출합니다.
- **실행 명령**:
  ```bash
  node .agents/skills/woohyun-tracker/scripts/analyze_data.js
  ```

## 📋 하네스 워크플로우

1. **기록 갱신/수정/모바일 기능 추가 시**:
   - `index.html` 또는 `server.js` 수정 후 `run_harness.js`를 실행하여 100% PASS 확인
2. **정기 분석/병원 진료 전**:
   - `analyze_data.js`를 실행하여 최근 집중도와 리바운드 현황 요약 리포트 확인 후 진료 상담 자료로 활용
